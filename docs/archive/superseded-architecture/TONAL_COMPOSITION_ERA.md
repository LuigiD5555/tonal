# Tonal composition-era definition — archived

Before the T1 runtime and Architecture R2, Tonal was defined primarily as an optional composition/reproducibility layer that pinned exact component revisions and recorded provenance/compatibility.

That layer remains useful infrastructure, but this definition of Tonal as a whole is superseded.

Current authority defines Tonal as the complete heterogeneous runtime and research system; composition/pinning/provenance are infrastructure within that larger system.

Use Git history for the exact pre-R2 `PROJECT_BOUNDARY.md` and related root documentation.
