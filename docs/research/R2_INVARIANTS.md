# R2 runtime migration invariants

- T1 experiment semantics remain frozen.
- Parrot has no privileged runtime path.
- Capability selection is separable from execution.
- Verification authority is separable from executor authority.
- Tlaloc develops/qualifies capabilities; Tonal runs workflows.
- Origami is optional and independently testable.
- Shponglese semantics are codec-independent.
- New research mechanisms enter through falsifiable experiments, not architecture-by-analogy.
